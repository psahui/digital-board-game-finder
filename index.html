Notes

Board Game Arena Premium: many BGA games are free for everyone. For Premium games, BGA's rule is that only the player who creates the table needs Premium — everyone else joins free. One subscription covers a whole group.

Steam Remote Play Together: one person owns the game and streams it; friends join from their own Steam without buying it. Only works for games with local multiplayer.

Tabletop Simulator / Tabletopia: official DLC for those apps — a faithful virtual copy of the physical game, with no rules enforcement. Each player usually needs the base app.

Steam matches are found by name and checked by hand, so the odd miss is possible. Prices are Steam's current AUD prices at the last refresh — check the store page before buying.
